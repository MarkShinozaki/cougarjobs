# CougarJobs

A focused job exploration and networking starter for **Washington State University** students — browse sample Northwest jobs and jump to LinkedIn people search by industry. No signup required.

## Features

- **Jobs** — Search and filter sample listings in WA, OR, ID, and nearby (remote, type, keywords).
- **Network** — Industry cards with connection tips and LinkedIn search links (sample data only).

## Getting started

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
bun dev      # Development server
bun build    # Production build
bun start    # Production server
bun lint     # ESLint
```

## Stack

Next.js (App Router), TypeScript, Tailwind CSS v4, Lucide icons, Bun.
